PRIVACY

What this site stores is nothing.

There are no accounts, no cookies, no analytics script and no database behind this page. A request arrives, a file is returned, and that is the whole thing.

What we store

  • Nothing about you. No identifiers, no profiles, no cookies, no third-party trackers, no advertising pixels. There is no login, so there is nothing to log in to.
  • Server logs, briefly. Like any web server, the host keeps request logs — IP address, timestamp, URL — for a short period, for capacity and abuse control. They are not used to build a profile of you.
  • Your colour scheme. The light/dark choice is stored in your own browser, in localStorage. It never leaves your machine.

What the links on this page carry

A datalink is public by construction: whoever holds the string holds the data. Two things follow.

  • Query strings travel. They end up in server logs, browser history, chat transcripts, referrer headers and screenshots. Treat a link as public the moment you send it.
  • Short links are not private. They hide the data, not the fact that a link exists — and the destination stays fetchable.
The rule we hold ourselves to: if it should not appear in a screenshot of somebody's address bar, it does not belong in a datalink. No secrets, no tokens, no personal data, no internal identifiers.

Third parties

  • Charts and diagrams are rendered by x-cmd/draw, and slide decks by x-cmd/ppt. Requests to those services carry the parameters of the link you asked for — which is the data, so the data goes there.
  • Typefaces are your system's own. No web fonts are downloaded, so no font service sees you.
  • The repository is on GitHub; the skill is on ClawHub. Following those links takes you to their sites and their policies.

Questions

Open an issue on the repository. The thinking behind these rules — including the parts we have not settled — is written up in the blog.
