THE PROBLEM

The picture is not the data.

the picture

It shows; it does not hold

A chart can show you the shape of a hundred numbers. It cannot hand you the hundred numbers.

the model

It reads pixels

Given the picture, a model reconstructs the values by looking. It is good at that — and it is still a reading, and it cannot tell which parts it read and which it filled in.

the artefact

There is nothing to check against

The piece ships; the context that made it does not. Whoever reads it next — a person, an agent, you next year — has the picture, and no data to compare it to.

THE IDEA

Put the data in the link — so the link still says what it says when the service behind it is down.

The link the data is in it

Share it and the other side gets the exact context, not a picture of one — they can change it, add a comment, share it again. The numbers travel with the link: put it in a README, in a blog post, and it still means something when the service behind it is down. Stateless — no account, no cloud, nothing that has to stay running.

The picture a glance is enough

What a reader sees: the shape, the trend, the proportion — in one glance, without opening anything. The same visual language every time, so the attention goes to what the data means, not to how it is styled.

The numbers exact, quotable, no looking

What an agent reads: the numbers themselves, already in the address. It never reconstructs a value from pixels, never rounds one, never spends a vision token. It quotes the number — and it can do arithmetic on it.

TWO READERS

One link. Two readers. The same numbers.

the human · gets the picture

  • A picture says more than a thousand words. The shape, the trend, the proportion — what a paragraph would take to say, in one glance.
  • Easy to share, change, extend. Paste it into a README, a post, an issue — the other side gets the exact context, not a screenshot. They can change it, annotate it, share it again.

the agent · gets the data

  • Exact. The numbers themselves — no rounding, no OCR, no estimating from pixels.
  • No hallucination. It reads the data; it never invents a value.
  • Cheaper. The link is ~25 tokens; the same chart as SVG is ~1,100. One fetch, and the context window stays free.

the other half

No pile of pictures nobody can track.

A datalink is one line of text. Change a number and the picture changes with it: the repository stops filling up with images whose history nobody can read, and every copy of the document stays in step with the data.

what the reader gets

A report that looks finished

Charts from one renderer, the same every time — not whatever the agent improvised that day.

what stays behind

Links that still hold the data

Every picture is a link with the numbers inside it. Nothing was flattened on the way.

what it means later

Memory that can be re-read

Six months on, an agent with memory reads the link and finds the intent and the numbers — not a picture of them.

That last one is the real prize. A chart in a chat log is a dead end: the numbers behind it are gone, and whoever reads it later has to reconstruct them from pixels. A link keeps the numbers — and its parameters say what was being measured and how it was framed. That is what makes a report something an agent can work from again, instead of something it has to take on faith.
TWO CASES

Two costs you stop paying.

case one

Your README has numbers in it

Today. The number changes, so the chart is re-rendered, re-uploaded and committed as a binary. The repository grows, and the diff says “image changed” — not what changed.

With a datalink. The agent changes one number in the URL and commits. The diff shows the number, the picture follows it, and a year later the history still says what you meant.

case two

You ship the same docs in five languages

Today. Six languages, six chart files, six renders, six commits — and every change to the data means doing it six times.

With a datalink. The language is a parameter. Six charts, six URLs, one line of text each — generated from the same source by the same agent.

WHAT ELSE

It is not only charts.

Every tab is one link. datalink.ac/draw is the same service as x-cmd.com/draw — the address is the only difference. Click any picture to open it in the explorer and change it by hand.
