A picture is not the data.

  • The chart shows the shape, not the values.
  • Your AI reads pixels back — exact for a bar, a guess for a label.
  • Later nobody can check the number: reader or agent.

your README

The number stays in the link

Today the number changes, so the chart is re-rendered, re-uploaded and committed as a binary: the repository grows, and the diff says “image changed” instead of what changed. With a datalink the agent changes one number and commits — the diff shows the number, and a year later the history still says what you meant.

six languages

Six URLs, not thirty-six files

Six languages mean six chart files, six renders, six commits — and every change to the data means doing it six times. With a datalink the language is a parameter: six charts, six URLs, one line of text each, generated from the same source by the same agent.

The link also records what was measured and how — so a report stays readable by an agent months later.
