Ask an agent for a chart and you get a chart. Ask it for the release calendar,
or the slide deck, or the map of last quarter's sales, and it hands you the
same kind of thing: a link.

Same parameters, four pictures. The string after the `?` is identical in all
four; what differs is which renderer reads it.

A description of data says what was measured. It does not say how it should
be drawn — and that is why the same data can be a chart, a table, a calendar
or a slide.

## The renderer is a service; the format is a contract

A renderer is a program behind a host, and it can be replaced: another host
may implement the same contract. What it cannot change is the contract — the
promises every renderer has to keep, written down in the
[specification](/spec).

So a new kind of picture — a molecule, a Gantt chart, a kind nobody has
thought of yet — is not a new format. It is the same parameters, read by a
different renderer.
