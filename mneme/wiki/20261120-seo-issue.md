## 定位关键词（edwinjhlee 定，2026-11-20）

datalink 的文章要提这五个词：

**ai · agent · markdown · vibe coding · development**

为什么这么定：搜索意图跟着时代走。vibe coding 成为日常之后，
开发的交接现场（issue / PR / README）是 agent 写的 markdown；
「图进不进得了这个现场」正是 datalink 要回答的问题。
文章里把这五个词讲清楚，等于把自己挂进读者正在搜的那件事上。

注意这不是关键词堆砌——每处埋入都要顺带说一句机制（站里的老规矩：
机制 + 回报）。#2（六种语言）和 #8（URL 会暴露什么）没埋：
前者是 README 国际化案例，后者是隐私篇，硬塞会稀释各自的论点。

## 搜索引擎要显示图标 logo（edwinjhlee 要求）

已做（4c1a5ab）：

- **`/favicon.ico`**（48/32/16 多尺寸，站点根目录）——Google 结果页
  的 favicon 抓取器默认找根目录的 ico；只有 `<link rel="icon">` 的 SVG
  在结果页经常不显示。
- **`/apple-touch-icon.png`**（180×180）——替换原来拿 og.png 凑数的做法。
- **`/assets/logo.png`**（512×512）——供结构化数据引用。
- **Organization JSON-LD**（layout.html，`logo` 字段指向 logo.png）。
  注意：build.mjs 本来就会给每页发一个 WebSite JSON-LD（带 description），
  所以 layout 里只补 Organization，**不要**再写一个 WebSite，会重复。

制作过程中的一个坑：ImageMagick 自带的 SVG 渲染器画不出这条品牌标
（输出只有底色方块）。最后用浏览器渲染 SVG 再截图位图化，才是正确的那张。

## 还没定的

- **SERP favicon 何时出现**：Google 抓取 favicon 的节奏不可控，
  只能靠 Search Console 观察。图标文件已就位。
- **logo 知识面板**：Organization JSON-LD 只是申报，Google 给不给面板
  取决于站点知名度，急不来。
- 继承 [[20261112-datalink-seo]] 的未决项：`/draw` 要不要 noindex、
  每页独立 OG 图、双语 canonical 策略。
- Search Console 接入仍是唯一真相来源（这个站没有统计脚本，
  见 [[20261112-datalink-privacy]]）。
